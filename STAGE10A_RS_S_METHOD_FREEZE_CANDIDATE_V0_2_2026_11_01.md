## 3. Fixed chronology, missingness, comparison unit and stopping

- Labels are usable at logical `origin+5000` only after the prediction has been durably committed. No generation, selection, confirmation or later audit row may leak into an earlier operation.
- Each S variant inherits seed 0–4 and its arm's **exact source opportunity IDs**; up to four slots, no chasing a later favorable clock. Independent confirmation consumes future rows, so skipped opportunities due to pending work, checkpoint supersession and end-of-stream censoring are *observed design outcomes*, not missing values to impute. Record denominator of eligible, attempted, selected, confirmed, published and censored opportunities per arm/seed.
- The primary causal sample remains **five paired seeds**. Report every seed separately and descriptive mean, median, min/max of S-vs-R difference for post-regime MCC and unchanged MCSC, also full-stream coverage and rule authority durations. Do not infer independent significance from opportunities, rows or bootstrap draws. No adaptive stopping or extra seeds.
- S-drift and S-periodic consume identical sealed Phase-A events and checkpoints. No real S path may run until G2 Phase-A custody and read-only Phase-B separation are proven. The S protocol **must be registered before any Stage-10A treatment**; for each seed, run one authorized common Phase A and only then R and all registered S variants as *independent read-only Phase-B consumers* of that identical sealed trajectory. Their definitions, schedules and inference status must be frozen *before* Phase A starts. Failed S variants are retained as failed outcomes, not silently omitted.
- Prespecified invalid/absence semantics: no candidate = zero new authorities; insufficient/censored confirmation = none; unverified chronology, label leakage, changed neural ancestry, inconsistent checkpoint chain, or unprespecified source change = **invalid entire affected seed**, retain attempt and do not impute outcomes. Report all valid/invalid/blocked seeds; no replacement seed. Failure to complete all five for valid inference requires separate transparent scientific disposition, not selective exclusions.

## 4. Explanation fields and denominators

Evaluator computes pre [0, 69,260) and post [69,260, 138,530) only **after Phase B sealing**. Define `I_y` as evaluator-class rows, `covered` as exactly one actionable symbolic class emitted, and `abstain` as unresolved conflict or no symbolic rule. For each class y ∈ {BENIGN=0, GoldenEye=1}, report:
- `coverage_y = count(I_y & covered)/count(I_y)`; `correct_coverage_y = count(I_y & covered & symbolic_class=y)/count(I_y)`; `correct_on_covered_y = correct/covered_y` with **NA**, not zero, when the covered denominator is zero. Frozen MCSC stays the macro mean of class-specific **correct coverage**; never redefine it.
- `fidelity_y = count(I_y & covered & symbolic_class=neural_decision)/count(I_y & covered)`, NA if no covered rows. `conflict_rate = count(conflict_abstain)/n`; `uncovered_rate=count(uncovered)/n`; explicitly distinguish both and show their overlap where meaningful.
- Complexity = antecedent condition count over active rule versions, with unweighted mean/median and rule-age-weighted mean labeled separately. Rule churn = number of new version additions + authority withdrawals per 10,000 predictions (also raw count). Rule age at clock t = t - first `valid_from` for that lineage, never negative. Version persistence = count of predicted rows over which version is active; show right-censor. Staleness = maturity-complete quality-failing checks per eligible active rule-check, with NA for zero denominator; recovery = clock distance from demotion to the next valid active restoration, right-censored if absent. Temporal continuity = fraction of consecutive prediction clocks with unchanged active semantic-rule ID set; denominator `n-1`; explicit NA for n <=1. 
- Report attack recall/FNR and normal-class FPR using the **frozen fused scores and thresholds**; compute overhead as per-opportunity SHAP/surrogate/lifecycle seconds and total inference/update time, separating neural and symbolic work. No claims of clinical/expert explanation reliability solely from these proxies.
