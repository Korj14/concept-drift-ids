# Stage 10A — privileged online prediction/label escrow backend

**Role:** WARM evidence for a concrete G2 production-path component. It is not a scientific amendment, a frozen operational schema, independently attested production deployment, a completed G2 gate, or Stage 10A RELEASE. Frozen source and checkpoint receipts remain immutable.

## What is now implemented

`src/concept_drift_ids/stage10a_privileged_escrow.py` is a real Unix-domain transport compatible with `Stage10AControlPlaneRunner.run(..., label_gateway=...)`. An independently privileged root controller prepares `attempt/ipc` for the already accepted source-custody layout: root-owned attempt directory 0711, escrow-owned private `escrow/labels.npy` mode 0400 under 0500, and escrow-owned IPC directory SGID 2710 with writer group **traverse only**. A daemon under its distinct escrow UID verifies the pinned private-label bytes and enforces `SO_PEERCRED` writer UID, exact attempt/seed/run/row ID, monotonic clock, unchanged 5,000-row maturity, exact 138,530-row stream, checkpoint-hash shape, and finite neural probability. The writer never receives raw labels or the label file descriptor.

Before returning any response, the daemon appends a canonical hash-chained prediction event to its escrow-owned `0600` journal and calls kernel `fsync`. For clocks at least 5000 it then appends and `fsync`s the matured-label grant event, returning exactly origin `clock - 5000`. If the append, fsync, peer-credential check, validation or socket connection fails, the call raises/stops rather than releases an uncommitted label. The single attempt is write-once: an incomplete journal prevents restart under the same IPC path. A complete stream receives an explicit right-censor-aware terminal event, read-only mode, and directory sync. No code path loads original model checkpoints or initiates Stage 10A predictions.

**Actual bounded test:** The production daemon and client run as different Linux kernel UIDs/GIDs via `setpriv`, using a disposable private `138530`-entry label vault (not original scientific labels). The writer commits clocks 0–5000 and receives exactly the origin-0 label after clock-5000 durable append. The test checks real kernel denial of writer reads against the private labels and journal, monotonic hash-chain integrity, and preservation of the incomplete attempt against restart. Negative tests reject substituted identities/early clocks and injected fsync failure. This is a controlled test of the actual daemon and caller, **not** an experiment or independent host attestation.
